# SPEC-028：取消影响首次读取的生命周期同步

- 状态：`Accepted`
- 创建：2026-09-02
- 优先级：P2
- 关联：SPEC-005、SPEC-007、SPEC-023

## 1. 已复现

用户基于旧 `SCHEDULED` 快照打开取消排期；另一协作者已经取消或删除。`GET /unschedule-impact` 返回 409/404，但页面把所有错误都当成可重试网络失败，永久展示“重新读取名单”，底层卡片也不更新。

## 2. 规则

- 首次或重读影响快照遇到 409 `TOPIC_STATE_CONFLICT`：关闭失效确认、同步最新状态并给出可理解提示。
- 遇到 404：关闭确认、移除已删除卡片并定位稳定页面状态。
- 仅网络、5xx 等临时失败保留弹窗和“重新读取名单”；不能把确定性生命周期冲突伪装为可恢复网络错误。
- 所有分支不得发送取消写请求。

## 3. 验收

桌面和 Pixel 7 对真实 409/404 覆盖弹窗关闭、底层同步、焦点和零 `/unschedule` POST；临时 500 重试与名单保护保持通过。
