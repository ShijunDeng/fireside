# SPEC-031：全局导航触控边界

- 状态：`Accepted`
- 创建：2026-09-02
- 优先级：P2
- 关联：SPEC-011、SPEC-015、SPEC-024

## 1. 已复现

Pixel 7、820px 平板和桌面浏览器中，顶部品牌“围炉夜话，返回顶部”高约 30px，页脚品牌高约 27px；页脚“议题 / 活动 / 往期”短链接宽约 40px。它们都是实际导航控件，却未达到系统既定的 `44×44px` 最小触控区域。

## 2. 规则

- 顶部品牌、页脚品牌和全部页脚任务导航链接的可点击边界均至少 `44×44px`；短中文标签不得因文字宽度缩小命中区。
- 扩大命中区不得造成页头高度跳变、页脚横向溢出、导航文本截断或错误的视觉主次。
- 键盘焦点、返回顶部行为、导航 current 状态和减少动态效果逻辑保持不变。

## 3. 验收

在 1440px、820px 与 Pixel 7 实测每个全局导航控件边界，宽高均不少于 44px；整页无横向溢出，顶部/页脚品牌能返回顶部，页脚三条任务链接仍进入正确视图。
