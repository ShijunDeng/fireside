# SPEC-026：活动详情合法极端文本布局边界

- 状态：`Accepted`
- 创建：2026-09-02
- 优先级：P1
- 关联：SPEC-011、SPEC-022

## 1. 已复现

API 合法上限的连续 Latin 标题（80）、简介（500）、分享人（30）、标签（20）和地点（60）排进本周后，从周历打开公开活动详情：桌面/820px 弹窗 `clientWidth=678`、`scrollWidth=5037`；Pixel 7 弹窗 `390/5522`。正文和操作被推到可视区外。SPEC-022 只覆盖卡片与海报，未覆盖活动详情。

## 2. 规则

- 所有活动详情 Grid/Flex 子项允许收缩；用户文本在语义容器内安全断词。
- 弹窗自身及页面不得产生横向溢出；不缩小 API 字段上限，不静默截断 DOM 正文。
- 正常中文、URL 脱敏、按钮与 44px 触控布局保持不变。

## 3. 验收

桌面、820px、Pixel 7 使用合法上限夹具从周历打开详情；标题、简介、标签、分享人、地点和动作都留在弹窗宽度内，`scrollWidth <= clientWidth`，页面无横向溢出。
