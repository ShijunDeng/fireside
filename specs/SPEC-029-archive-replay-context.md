# SPEC-029：往期回顾的完整活动与收获上下文

- 状态：`Accepted`
- 创建：2026-09-02
- 优先级：P2
- 关联：SPEC-004、SPEC-011

## 1. 已复现

归档活动在列表卡片只显示收获，不显示原时间、地点和时长；从月/周历进入详情则显示活动信息，却不显示必填 takeaway。没有 materialUrl 时，任何单个视图都无法回答“何时、在哪里、讲了什么、留下什么”。

## 2. 规则

- `ARCHIVED` 列表卡片展示只读原排期、时长和安全地点，同时展示本期收获；历史日期必须包含四位年份，避免跨年度的同月同日产生歧义；不恢复报名、会议或生成海报动作。
- 归档活动详情展示“本期收获”正文；资料链接仍为可选，有值才显示入口。
- 公开回顾不泄露会议 URL/凭证或报名姓名，现有归档纠错动作不变。
- 极端文本继续遵守弹窗与卡片宽度边界。

## 3. 验收

使用无 materialUrl 的真实归档：往期列表在同一卡片看到包含四位年份的日期/时间、地点、时长和收获；月或周历详情看到同样包含年份的核心上下文；无会议入口、无虚假资料按钮、无横向溢出。桌面与 Pixel 7 通过。
