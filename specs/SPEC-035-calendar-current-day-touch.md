# SPEC-035：横向日历的今日定位与活动触控边界

- 状态：`Accepted`
- 创建：2026-09-02
- 优先级：P2
- 关联：SPEC-002、SPEC-011、SPEC-019、SPEC-021、SPEC-024

## 1. 已复现

- 在北京时间 2026-09-06（周日），820px 与 Pixel 7 月历先切换其他周期再点“今天”，cursor 虽回到当月，`.month-scroll` 仍保持 `scrollLeft=0`；今日单元格在右侧可视区外。周历已定位今日，月历没有对等逻辑。
- 820px 平板已进入移动菜单和横向日历交互，但月历 `.calendar-event` 高度仍为 34px；Pixel 7 才在 720px media query 得到 44px。最核心的“打开活动”入口在平板上低于项目统一触控基线。
- 第 33 轮在 393px/320px 实测月/周历“上一周期/下一周期”仅约 39.22×44px：Flex 导航组允许两个固定宽度按钮收缩，增加翻页误触。

## 2. 产品规则

- “今天”不只改标题/cursor，还必须让今日列在月历和周历的局部横向可视区内；不得依赖用户再手动横滚。
- 月历今日定位只滚动 `.month-scroll`，不改变整页滚动、不把页面宽度撑出视口；左侧日期允许保持起点，右侧日期应带少量内边距完整显示。
- 切换到月/周视图、点“今天”或在当期重定位时都执行可见性校正；点“上/下一周期”仍保持新周期的自然起点，不应错误滚到不存在的今日。
- 所有使用横向月历的紧凑视口（至少移动菜单断点 `<=1000px`），活动按钮真实高度不少于 44px。仍只预览前 3 场，高密度当日通过“另有 N 场”进入完整议程。
- 日历前后周期按钮必须 `flex:none` 且真实宽高均不少于 44px；320/393 的标题、“今天”和导航组仍须完整可读、无工具栏或页面横溢。

## 3. 验收

- 固定北京时间为周日，在 820px 和 Pixel 7 分别进入月历、切换到其他周期、点“今天”；今日单元格左右边界均位于 `.month-scroll` 可见边界内（允许 4px 测量容差）。
- 820px 真实月历活动按钮宽高均不少于 44px；高密度 10 场仍只预览 3 场并可进入完整议程。
- 1440px 不强制改变紧凑密度；820px/Pixel 7 的 `documentElement.scrollWidth <= innerWidth`，月历局部横滚和周历今日定位均不回退。
- 320px 与 393px 分别进入月历和周历，两个周期箭头的 bounding box 均至少 44×44px，工具栏无相互遮挡或页面级横溢。
